# PCAP Documentation

PCAP is a Streamlit application for exploring patch-clamp current-clamp recordings and measuring action potential (AP) and afterhyperpolarization (AHP) kinetics.

Use the navigation to learn how to upload recordings, visualize events, export bulk metrics, and compare recordings across groups.

[Browse the source code](https://github.com/theafairfax/pcap)

!!! note "Scientific interpretation"
    Automated measurements depend on waveform quality, injection protocol, analysis parameters, and sampling rate. Validate important results against the original trace.
